
# Pixel Gallery

## About the Project

Pixel Gallery is a simple and responsive image gallery website. It allows users to explore images in an organized and attractive layout.

## Features

- Responsive image gallery
- Image categories and filters
- Interactive image display
- Lightbox image preview
- Simple and user-friendly design
- HTML, CSS and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Pixel-Gallery/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the image gallery.
